# Viceframe Studio

A dependency-free cover composer with flexible panels, photo positioning, cinematic color grades, editable type, and print-ready PNG export. A built-in vector scene makes the editor complete on first launch, and every feature works offline.

## Run

Open `app/index.html` in a modern browser, or serve it locally:

```sh
python3 -m http.server 8080 --directory app
```

Visit `http://localhost:8080`. Package the submission with `MAKEFUN_OUTPUT_DIR=/tmp/cover-output node main.ts`.
